inicio registro

formulario en html

texto

campos de textos basicos: simple, con placeholder,obligatorias (required), de solo lectura (readonly) y deshabitado (disabled)






contacto

campos especializados para datos de contacto: contraseña,correo electronico, telefono y URL, cada uno con si propio teclado y validacion en el navegador





numericos

campos para valores numericos: un numero con limites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.



fecha y hora

selectores nativos de fecha y hora: fecha,fecha y hora combinadas , hora, semana del año y mes






seleccion

controles de seleccion: elegir un color,marcar una casilla, elegir una opcion de un grupo de radios y subir un archivo.





lista desplegable

listas desplegables con el elemento select: una opcion simple, una con valor preseleccion (selected), una agrupada con optgroup,una de seleccion (multiple) y una deshabilitada (disabled).
